# Folder Tree Summary

## Root

The root holds product, architecture, security, privacy, editorial, source, scraping, AI safety, scale, cost, risk, data model, pipeline, and implementation sequencing documents. These files align the product before code exists.

## `.github/`

Plans future CI/CD, issue templates, pull request review, security disclosure, and ownership. No workflow YAML is included yet.

## `apps/`

Holds future application surfaces. `apps/web/` is the main Next.js App Router PWA. `apps/admin-later/` is reserved for a separate admin application if needed. `apps/mobile-later/` reserves Expo/React Native planning. `apps/storybook-later/` reserves future component documentation.

## `packages/`

Defines future shared packages for UI, config, types, validators, database, auth, permissions, AI, ingestion, geography, search, notifications, billing, observability, security, editorial, source registry, and test utilities.

## `services/`

Describes future worker services for background jobs, ingestion, AI, email, billing webhooks, source monitoring, and admin tools.

## `supabase/`

Documents future Supabase database, migrations, seed data, RLS policies, storage buckets, functions, backups, and plain-English schema docs.

## `docs/`

Contains the main knowledge base: architecture, frontend, backend, database, AI, ingestion, sources, security, privacy, product, design, deployment, operations, analytics, monetization, legal, testing, mobile, and expansion.

## `data/`

Contains source registry notes, prose mock data descriptions, taxonomies, seed plans, geography plans, and examples. No JSON data or executable fixtures are included yet.

## `prompts/`

Contains planning notes for future prompt families. It intentionally does not contain production prompts or executable prompt files.

## `evals/`

Plans evaluation datasets, rubrics, golden examples, red-team cases, regression checks, and scoring.

## `tests/`

Plans future frontend, backend, database, RLS, ingestion, AI, security, accessibility, end-to-end, and load tests. No test code exists yet.

## `infra/`

Documents future setup for Vercel, Supabase, Trigger.dev, Inngest, Upstash, Sentry, PostHog, Langfuse, Stripe, Resend, Apify, Browserless, Mapbox, and Terraform later.

## `scripts/`

Documents the no-code policy for this pass and lists future scripts that may be added after approval. No executable scripts are included.

## `operations/`

Holds launch, review, source health, AI quality, security, privacy, correction, failure, and support workflows.

## `legal/`

Plans terms, privacy policy, disclaimers, scraping compliance, election risk, data processing, public records, and corrections policy.

## `brand/`

Documents messaging, voice, design language, product copy, trust copy, and accessibility copy.

## `research/`

Organizes competitor, market, source, user, policy, and technical research.

## `public-assets/`

Reserves future logos, icons, illustrations, demo images, and source icons. No image assets are included yet.
