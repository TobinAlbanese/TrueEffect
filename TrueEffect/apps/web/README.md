# TrueEffect Web App Plan

This folder is reserved for the main Next.js App Router application for public pages, dashboard, admin routes, and the PWA MVP.

## Architecture-Only Status

No application code exists here yet. This folder currently contains route plans, frontend architecture notes, component plans, security notes, and placeholder route README files.

## Future Scope

- Public marketing and trust pages.
- ZIP onboarding and profile setup.
- Today feed, My Town, Ask TrueEffect, Watchlist, and Issue detail pages.
- Admin review dashboard and source management routes.
- PWA support, accessibility, SEO, performance, and responsive behavior.
