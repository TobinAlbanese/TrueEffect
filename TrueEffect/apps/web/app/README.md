# App Router Root

## Page Purpose

Root planning area for future App Router layouts, route groups, metadata, and global boundaries.

## User Type

All users and system routes.

## Data Needed

Global shell data, auth session state, feature flags, and safe public metadata.

Root layout, providers, metadata boundary, error and loading states.

Planning only.
