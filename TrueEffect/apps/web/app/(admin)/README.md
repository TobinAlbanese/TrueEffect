# Admin Route Group

## Page Purpose

Admin and reviewer workflows for sources, events, cards, users, corrections, and audit logs.

## User Type

Reviewers, editors, admins, owners.

## Data Needed

Role claims, review queue, source registry, draft content, audit logs.

## Eventual Components

AdminShell, ReviewQueueTable, SourceDrawer, CorrectionBanner.

## Security Considerations

Requires strict RBAC, admin audit logs, and draft content isolation.

## MVP Status

MVP for review dashboard.

## Future Expansion

Split into separate admin app if complexity grows.
