# Auth Route Group

## Page Purpose

Routes for sign in, sign up, password recovery, and future OAuth.

## User Type

Anonymous and authenticated users.

## Data Needed

Auth provider configuration, redirect targets, session state.

## Eventual Components

Auth layout, forms, error messages, security notices.

## Security Considerations

Never expose service-role keys. Rate limit auth attempts.

## MVP Status

MVP.

## Future Expansion

Add OAuth, MFA, and device/session controls later.
