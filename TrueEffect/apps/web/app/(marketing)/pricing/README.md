# Pricing Page

## Page Purpose

Explain mock Free, Plus, Pro, and Team plans for the frontend MVP.

## User Type

Anonymous visitors and signed-in users.

## Data Needed

Plan names, feature lists, and frontend-only FAQs.

## Components

Pricing cards, feature summaries, and waitlist calls to action.

## Security Considerations

Do not add payment logic, checkout links, entitlement logic, or live billing copy.

## MVP Status

Frontend MVP.

## Future Expansion

Backend billing is out of scope for this MVP.
