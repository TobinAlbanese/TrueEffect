# Ask TrueEffect Page

## Page Purpose

Let users ask grounded questions about relevant issues.

## User Type

Authenticated users.

## Data Needed

User question, profile context, retrieved published sources, usage limits.

## Eventual Components

AskTrueEffectPanel, answer view, source citations, feedback controls.

## Security Considerations

Rate limit, avoid professional advice, and ground answers in approved sources.

## MVP Status

MVP.

## Future Expansion

Add saved answers, follow-up questions, and paid limits.
