# Today Feed Page

## Page Purpose

Show the user the most relevant current impacts.

## User Type

Authenticated users.

## Data Needed

Published impact cards, relevance scores, profile, location, watchlists.

## Eventual Components

ImpactCard, ImpactLevelBadge, LifeAreaTag, ConfidenceBadge, SourceDrawer.

## Security Considerations

Only published content and owner-scoped personalization should be visible.

## MVP Status

MVP.

## Future Expansion

Add filters, saved views, and urgency sorting.
