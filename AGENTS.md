# True Effect Frontend Rules

- This is the True Effect frontend MVP.
- Use mock data only.
- No backend integrations yet.
- No Supabase setup yet.
- No AI API calls yet.
- No Stripe billing yet.
- No scraping yet.
- No real auth yet.
- Prioritize readable, accessible, responsive UI.
- Keep pages calm, clear, and nonpartisan.
- Use semantic design tokens so the color scheme can be replaced later.
- Every page should be understandable to older and non-technical users.
- Do not create dense dashboards, infinite feeds, or doom-scroll experiences.
